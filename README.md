# مرصاد — مساحة عمليات حسب الدور

واجهة عربية جديدة لمتابعة العمليات والطلبات والرسوم، مبنية بـ React وNext.js، مع API عبر FastAPI وقاعدة PostgreSQL على Neon.

## الأدوار ومسارات العمل

- **مسؤول قواعد البيانات:** صلاحيات تشغيلية كاملة على مخططات العمليات والتدريب، وإدارة أدوار الحسابات من صفحة «الصلاحيات»، ومراجعة التعديلات المتكررة، ومتابعة سجل أوامر SQL.
- **قائد الشرطة:** استعلامات SQL للقراءة على كل سجلات العمليات وبيانات التدريب، والتحقق من السجلات والرسوم، وتوجيه طلبات العمدة ثم اعتماد النتيجة قبل عرضها.
- **الضابط:** استعلامات SQL للقراءة على سجلاته وبيانات التدريب، وإضافة عمليات وتعديلها بشكل محدود، وإنشاء رسوم للمراجعة.
- **العمدة:** استعلامات SQL للقراءة على السجلات المعتمدة فقط، وعرض الرسوم المعتمدة، وإرسال طلب بيانات إلى قائد الشرطة.

تظهر مهام الدفترين المكانيين في صفحة «مهام التحليل المكاني»، وتنفذ الاستعلامات على اتصال PostgreSQL الفعلي. تجهز الخدمة جداول التدريب المكانية داخل `spatial_lab`. تُحفظ تغييرات البيانات والأدوار والطلبات في سجلات تدقيق. يسجل سجل SQL اسم الموظف ودوره ووقت تنفيذ كل استعلام، ويعرض مسؤول قواعد البيانات هذه التفاصيل في صفحة «سجل أوامر SQL». عند انقطاع Neon، تحفظ أوامر SQL في صندوق محلي مشفّر، ثم يُعاد التحقق من نشاط الحساب ودوره قبل التنفيذ. يمنع معرّف الأمر إعادة تطبيق التعديلات التي سبق اعتمادها في قاعدة البيانات.

## تمارين تحليل المناطق والتسليم

تتضمن صفحة المهام أيضًا تمارين الدفترين `02_district_month_analytics_team_project_student.ipynb` و`03_dashboard_export_and_reporting_handover_student.ipynb`. يمكن لكل دور تشغيل استعلامات التمارين الثمانية بصلاحية قراءة على البيانات التدريبية الاصطناعية، ومشاهدة رسم مناسب لنتيجة كل استعلام بجانب جدول البيانات، مع بقاء صلاحيات بيانات العمليات خاضعة لدور الحساب. تشمل التمارين توزيع الجرائم والحوادث حسب المنطقة والشهر، تغطية المصادر، الإصابات، المجاميع الشهرية، و`LAG` حسب المنطقة.

تظهر صفحة «لوحة المناطق والتصدير» ملخص 2025 على مستوى المنطقة-الشهر، وتتحقق من المطابقة بين سجلات المصدر والتقرير واكتمال 12 شهرًا لكل منطقة. توفر تنزيل CSV وملف provenance بصيغة JSON مع ملاحظات التسليم. تنشئ الخدمة المناظير `spatial_lab.assigned_crime` و`spatial_lab.assigned_traffic` و`spatial_lab.integrated_report`، وتستخدم `ST_Covers` مع اختيار رقم المنطقة الأصغر عند تعادل حدود المناطق.

## تشغيل محلي

1. انسخ `.env.example` إلى `.env`، وأضف رابط Neon في `NEON_ADMIN_DATABASE_URL`.
2. ضع بريد مسؤول قواعد البيانات في `INITIAL_ANALYST_EMAIL`، ثم سجّل بهذا البريد واختر كلمة مروره.
3. عناوين الدخول المقترحة لبقية الأدوار هي `commander@mirsad.example` و`officer@mirsad.example` و`mayor@mirsad.example`. ينشئ مسؤول قواعد البيانات هذه الحسابات من صفحة «الصلاحيات» ويحدد أدوارها وكلمات مرورها الأولية. هذه معرّفات دخول داخل التطبيق وليست صناديق بريد حقيقية.
4. أنشئ مفتاح Fernet وضعه في `OFFLINE_QUEUE_KEY`، وضع سر جلسات عشوائيًا في `SESSION_SECRET`.
5. شغّل FastAPI من جذر المشروع:

   ```sh
   uv sync
   uv run uvicorn backend.app:app --reload --port 8000
   ```

6. شغّل الواجهة:

   ```sh
   cd frontend
   npm install
   npm run dev
   ```

   افتح `http://localhost:3000`.

عند بدء الخدمة تُنشأ مخططات التطبيق، وتُجهز صلاحيات PostgreSQL والسياسات المقيدة. مخطط `app_private` مخصص لحسابات الدخول وسجلات التطبيق ولا يظهر في محرر SQL.
